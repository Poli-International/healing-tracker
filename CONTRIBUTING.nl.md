# Bijdragen aan de Genezings-Tracker

Hartelijk dank voor uw interesse om bij te dragen! Deze tool maakt deel uit van de Poli International widgetsuite.

## 🛠️ Ontwikkelingsconfiguratie

1. **Fork en kloon de repository**

```bash
git clone https://github.com/Poli-International/healing-tracker.git
```

2. **Geen buildproces vereist**
   Deze tool is gebouwd met pure HTML/CSS/JS. Open `index.html` in uw browser om te testen.
