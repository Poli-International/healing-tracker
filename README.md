## 🎯 Overview

The Tattoo Healing Tracker is a digital companion for anyone with a new tattoo. It allows users to track their healing journey day-by-day, providing visual guides for what to expect at each stage and sending reminders for essential aftercare steps.

**Key Use Cases:**

- Tracking daily healing milestones
- Logging aftercare routine completion
- Early identification of potential healing issues

**Target Audience:**

- Hand-poked and machine tattoo clients
- Artists (for monitoring client progress)

---

## ✨ Features

- ✅ **Healing Milestones** - Interactive timeline showing common skin transformations.
- ✅ **Aftercare Logging** - Check off cleaning and moisturizing sessions.
- ✅ **Symptom Checker** - Guidance on what's normal and what requires an artist's attention.
- ✅ **Responsive Design** - Works on desktop, tablet, and mobile.
- ✅ **Free & Open Source** - MIT licensed.
