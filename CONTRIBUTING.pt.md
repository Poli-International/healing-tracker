# Como contribuir para o Monitor de Cicatrização

Obrigado pelo seu interesse em contribuir! Esta ferramenta é parte do catálogo de utilitários da Poli International.

## 🛠️ Configuração de Desenvolvimento

1. **Fazer fork e clonar o repositório**

```bash
git clone https://github.com/Poli-International/healing-tracker.git
```

2. **Sem processo de compilação**
   Esta ferramenta foi construída com HTML/CSS/JS puro. Abra `index.html` no seu navegador para testar.
