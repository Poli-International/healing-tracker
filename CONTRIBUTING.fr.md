# Contribuer au Suivi de Cicatrisation

Merci pour votre intérêt à contribuer ! Cet outil fait partie de la suite d'outils de Poli International.

## 🛠️ Configuration de Développement

1. **Forker et cloner le dépôt**

```bash
git clone https://github.com/Poli-International/healing-tracker.git
```

2. **Aucun processus de build requis**
   Cet outil est conçu en HTML/CSS/JS natif. Ouvrez `index.html` dans votre navigateur pour tester.
