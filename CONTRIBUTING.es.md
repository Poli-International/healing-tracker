# Cómo contribuir al Seguimiento de Cicatrización

¡Gracias por tu interés en colaborar! Esta herramienta forma parte del catálogo de utilidades de Poli International.

## 🛠️ Entorno de Desarrollo

1. **Bifurca y clona el repositorio**

```bash
git clone https://github.com/Poli-International/healing-tracker.git
```

2. **Sin proceso de compilación**
   Esta herramienta está creada con HTML/CSS/JS estándar. Abre `index.html` en tu navegador para realizar pruebas.
