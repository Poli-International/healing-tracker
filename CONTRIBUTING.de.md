# Mitwirken am Heilungs-Tracker

Vielen Dank für Ihr Interesse an einer Mitwirkung! Dieses Tool ist Teil der Poli International Tool-Suite.

## 🛠️ Entwicklungsumgebung

1. **Repository forken und klonen**

```bash
git clone https://github.com/Poli-International/healing-tracker.git
```

2. **Kein Build-Prozess erforderlich**
   Dieses Tool basiert auf reinem HTML/CSS/JS. Öffnen Sie `index.html` einfach in Ihrem Browser zum Testen.
